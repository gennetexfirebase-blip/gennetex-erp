JavaScript
JavaScript гэж юу вэ
JavaScript (товчоор JS) нь HTML, CSS-ийн хамт Вэбийн суурь технологиудын нэг болох програмчлалын хэл юм. Вэб сайтуудын 97 гаруй хувь нь хуудасны үйлдэлд JavaScript ашигладаг бөгөөд ихэвчлэн гуравдагч талын сантай хамт хэрэглэдэг.
Java & JavaScript
Java ба JavaScript-ийн гол ялгаа: Java нь объект хандалтат програмчлалын хэл, харин JavaScript нь объект хандалтат скрипт хэл. Java нь виртуал машин эсвэл хөтөч дээр ажилладаг програм бүтээдэг бол JavaScript код зөвхөн хөтөч дээр ажиллана. Java кодыг хөрвүүлэх шаардлагатай, харин JavaScript код текстээрээ ажиллана.
Java мэдэхгүйгээр JavaScript сурч болох уу?
JavaScript сурахын тулд Java мэдэх шаардлагагүй. Нэр нь төстэй ч хоёр хэл маш бага нийтлэг зүйлтэй бөгөөд огт өөр чиглэлд хэрэглэгддэг. Аль нэгийг нь түрүүлж сурч болох ч JavaScript сурахад Java урьдчилсан нөхцөл биш
JavaScript & EcmaScript
JavaScript нь ECMAScript стандартыг дагасан ерөнхий зориулалтын скрипт хэл юм. ECMAScript стандарт нь скрипт хэл бүтээх зураг төсөл бөгөөд JavaScript нь түүний хэрэгжүүлэлт юм. Ерөнхийдөө JavaScript нь ECMA-262-т тодорхойлсон ECMAScript стандартыг хэрэгжүүлдэг.

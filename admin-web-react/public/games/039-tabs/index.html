HTML

HyperText Markup Language буюу HTML нь вэб хөтөчид харуулах баримтын стандарт тэмдэглэгээний хэл юм. Үүнд CSS зэрэг технологи болон JavaScript зэрэг скрипт хэлүүд тусалдаг.

CSS

Cascading Style Sheets (CSS) нь HTML зэрэг тэмдэглэгээний хэлээр бичсэн баримтын харагдах байдлыг тодорхойлдог загварын хэл юм. CSS нь HTML, JavaScript-ийн хамт Вэбийн суурь технологи юм.

JAVASCRIPT

JavaScript (товчоор JS) нь HTML, CSS-ийн хамт Вэбийн суурь технологиудын нэг болох програмчлалын хэл юм. Вэб сайтуудын 97 гаруй хувь нь хуудасны үйлдэлд JavaScript ашигладаг бөгөөд ихэвчлэн гуравдагч талын сантай хамт хэрэглэдэг.

REACT

React нь UI бүрэлдэхүүн дээр суурилсан хэрэглэгчийн интерфейс бүтээх үнэгүй, нээлттэй эхийн front-end JavaScript сан юм. Үүнийг Meta болон бие даасан хөгжүүлэгч, компаниудын нийгэмлэг хөгжүүлдэг.

NODE

Node.js нь V8 хөдөлгүүр дээр ажилладаг, JavaScript кодыг хөтчөөс гадна гүйцэтгэдэг нээлттэй эхийн, олон платформын back-end орчин юм.

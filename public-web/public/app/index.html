Хувилбар ачаалж байна…

Хэрхэн суулгах вэ

  1. Дээрх товчийг дарж татна.
  2. Татаж дуусахад мэдэгдэл дээр дарж Суулгах гэж сонгоно.
  3. “Тодорхойгүй эх сурвалж” гэсэн анхааруулга гарвал Тохиргоо → Зөвшөөрөх гэж сонгоод буцна.
  4. Апп нээгдмэгц Google хаягаараа нэвтэрнэ.

Татагдахгүй эсвэл файл олдохгүй бол

Chrome зэрэг браузер APK файлыг “аюултай” гэж үзээд чимээгүй хаадаг. Татсан мэт харагдаад Downloads дотор байхгүй бол ихэвчлэн энэ шалтгаантай.

  1. Браузерын ⋮ → Татаж авсан зүйл (Downloads) хэсгийг нээнэ.
  2. Файл улаанаар “dangerous / blocked” гэж тэмдэглэгдсэн бол дэргэдэх ▾ дарж Үргэлжлүүлэх / Keep гэж сонгоно.
  3. Ажиллахгүй бол доорх шууд холбоосоор татна.

Нөөц холбоосоор татах →

Файл 135 MB тул Wi-Fi дээр татахыг зөвлөж байна. Татаж дууссан файл ихэвчлэн Файл → Downloads дотор байрлана.

Зөвхөн бүртгэлтэй ажилтан нэвтэрнэ.
Таны Google хаягийг админ урьдчилж бүртгэсэн байх шаардлагатай. Бүртгэлгүй хаягаар нэвтрэх боломжгүй. Хэрэв “Энэ Gmail хаяг зөвшөөрөгдөөгүй байна” гэж гарвал байгууллагынхаа админд хандана уу.

## 2. TURN сервер (хамгийн чухал)

### Яагаад хэрэгтэй вэ

WebRTC нь эхлээд хоёр утсыг **шууд** холбохыг оролдоно (P2P). Ихэнх гэрийн
Wi-Fi дээр энэ бүтнэ. Гэвч:

- оффисын галт хана
- зарим мобайл операторын CGNAT
- зочид буудал / нийтийн Wi-Fi

эдгээрийн ард P2P **бүтэхгүй**. Тэр үед дуу/дүрсийг дундын сервер
(TURN relay) дамжуулах ёстой. TURN байхгүй бол дуудлага "холбогдож
байна" дээр өлгөгдөөд таслагдана.

STUN (Google-ийн үнэгүй) аль хэдийн тохируулагдсан — гэхдээ STUN нь
зөвхөн хаяг олоход тусална, дамжуулахгүй.

### Тохируулах

`.env` файлд:

```
EXPO_PUBLIC_TURN_URL=turn:таны-сервер:3478
EXPO_PUBLIC_TURN_USERNAME=хэрэглэгч
EXPO_PUBLIC_TURN_PASSWORD=нууц-үг
```

> ⚠️ Эх кодод хатуу бичихгүй. `EXPO_PUBLIC_` угтвар нь эдгээрийг апп дотор
> харагдуулна — TURN-ийн хувьд энэ нь **зөв**, учир нь клиент тэдгээрийг
> мэдэх ёстой. Харин Supabase-ийн `service_role` түлхүүрийг ЭНЭ угтвартай
> хэзээ ч бүү тавь.

### Сонголтууд

| Хувилбар | Тайлбар |
|---|---|
| Өөрийн сервер (coturn) | Хамгийн хямд. Ubuntu VPS дээр `apt install coturn` |
| Cloudflare Calls | Үнэгүй эхлэлтэй, тохируулахад хялбар |
| Twilio / Metered | Ашиглалтын хэмжээгээр төлбөртэй |

## 3. Firebase (Android — апп хаагдсан үед дуудлага ирэх)

Апп бүрэн хаагдсан үед Supabase realtime ажиллахгүй. Утсыг сэрээх цорын
ганц зам нь **data-only, high-priority FCM мессеж**.

1. [Firebase Console](https://console.firebase.google.com) → төслөө сонго
2. ⚙️ **Project settings → Service accounts**
3. **Generate new private key** → JSON файл татагдана
4. Supabase-д secret болгож нэмнэ:

```bash
npx supabase secrets set FIREBASE_SERVICE_ACCOUNT="$(cat service-account.json)"
```

Үүний дараа `call-notify` функц өөрөө FCM руу илгээж эхэлнэ — код нь
бэлэн, зөвхөн түлхүүрийг хүлээж байна.

---

## 4. Apple VoIP (iOS — түгжээтэй үед дуудлага ирэх)

iOS дээр Android шиг "бүтэн дэлгэцийн мэдэгдэл" гаргах боломж **байхгүй**.
Түгжээтэй дэлгэц дээр дуудлага гаргах цорын ганц зам нь CallKit бөгөөд
түүнийг зөвхөн PushKit-ийн VoIP push сэрээж чадна.

1. [Apple Developer](https://developer.apple.com/account) → Certificates
2. **+ → VoIP Services Certificate** → App ID: `com.gennetex.erp`
3. Татаж аваад Firebase → **Cloud Messaging → APNs Certificates** руу байршуулна
4. `app.json` дотор entitlement аль хэдийн нэмэгдсэн:
   `com.apple.developer.pushkit.unrestricted-voip`

Үүнгүйгээр iOS дээр **апп нээлттэй байхад** дуудлага ажиллана, харин
түгжээтэй үед ирэхгүй.

## 5. Build хийх

Дуудлага нь native модуль (WebRTC) ашигладаг тул **Expo Go дээр ажиллахгүй**.

```bash
# Локал (компьютерт Android Studio байх шаардлагатай)
npx expo run:android

# Үүлэн дээр
eas build --profile development --platform android
eas build --profile production  --platform android
```

## 6. Бодит төхөөрөмж дээр шалгах жагсаалт

Хоёр өөр утас шаардлагатай. Тэмдэглэсэн зүйл бүрийг гараар шалгана уу.

**Үндсэн**
- [ ] Дуут дуудлага: залгах → дуугарах → хариулах → хоёр тал сонсогдох
- [ ] Видео дуудлага: хоёр тал бие бие рүүгээ харагдах
- [ ] Таслах → хоёр талд дуудлага хаагдах
- [ ] Дуудлагын хугацаа зөв тоологдож байна уу (хариулснаас хойш)

**Татгалзах, аваагүй**
- [ ] Татгалзах → дуудагчид "Дуудлагаас татгалзлаа"
- [ ] 45 секунд хариулахгүй → аваагүй болж түүхэнд улаанаар харагдана
- [ ] Дуудагч цуцлах → хүлээн авагчийн утас дуугарахаа болино
- [ ] Аваагүй дуудлагын мэдэгдэл ирж, дарахад түүх нээгдэнэ

**Хамгийн чухал — background/түгжээ**
- [ ] Апп background дээр байхад дуудлага ирнэ
- [ ] Утас **түгжээтэй** байхад дуудлага ирнэ
- [ ] Апп бүрэн хаагдсан үед дуудлага ирнэ *(FCM түлхүүр хэрэгтэй)*
- [ ] Түгжээтэй дэлгэцээс шууд хариулж болно

**Сүлжээ**
- [ ] Wi-Fi ↔ мобайл дата солиход дуудлага үргэлжилнэ (ICE restart)
- [ ] Өөр өөр сүлжээнд байгаа 2 утас холбогдоно *(TURN хэрэгтэй)*
- [ ] Сүлжээ бүрэн тасрах → "Сүлжээний холболт тасарлаа" гарна

**Хамгаалалт**
- [ ] Өөр рүүгээ залгах боломжгүй
- [ ] Аль хэдийн ярьж байгаа хүн рүү залгахад "завгүй" гарна
- [ ] Дуудлагын түүхэнд зөвхөн ӨӨРИЙН дуудлага харагдана

**Нөөц**
- [ ] Дуудлагын дараа камерын гэрэл унтарсан эсэх
- [ ] Микрофон чөлөөлөгдсөн эсэх (өөр апп дуу бичиж чадаж байна уу)
- [ ] Дуудлагын дараа батерей хэвийн зарцуулагдаж байна уу
